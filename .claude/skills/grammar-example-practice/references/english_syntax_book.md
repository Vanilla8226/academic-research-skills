## Notation the book uses in analyses

The book draws trees. In the HTML page, a labelled bracketing that uses the same labels is easier to read, e.g. `[S [NP They] [VP [V[intens] were] [AP[sC] [headA hopeful] [S'[finite clause] [Comp that] [S the weather would change]]]]]`.

Common labels: S, S' (clause with its complementiser), Comp, NP, VP, AP, AdvP, PP, N', headN, headA, headAdv, DET, ART, PRO, PropN, V[intens] / V[trans] / V[intrans] / V[complex], and functions in square brackets: [sC] subject complement, [oC] object complement, [dO] direct object, [iO] indirect object, [pO] object of a preposition, [opA] / [obA] optional / obligatory adverbial adjunct, [Pre-MOD] / [Post-MOD]. [Ɇ] marks an empty (covert) subject and ϕ an omitted complementiser, as in *Jack appeared eager (ϕ [Ɇ] to see her)*. In example sentences the book prints verbs in small capitals. Clause labels: EmNCl, EmACl, EmAdvCl (embedded nominal / adjective / adverb clause) and SubACl, SubAdvCl (subordinate adjective / adverb clause).

The book's own distinctions matter when choosing an example:
- **Embedded vs. subordinate** (§15.3, book pp. 78-79): an *embedded* clause is an argument (subject, object, complement) and can't be left out without making the sentence ungrammatical; a *subordinate* clause is an adjunct that can be left out.
- **Complement vs. modifier of an adjective** (§27-30, book pp. 117-121): an obligatory post-adjectival element is the *complement* of headA (*afraid that…*, *aware that…*); an optional one is a *post-adjectival modifier* (*anxious that…*, *glad that…*).
